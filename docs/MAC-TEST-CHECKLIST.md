# Mac shell — test checklist (from what the Windows remote hit on the home PC, 2026-11-18/19)

2026-11-19: "have a checklist from issues we ran into here, to test the mac when we do it". Every row below
went wrong at least once in the Windows remote (`ClaudeDeckNative.exe`) or the browser desk on the home PC (HOME-PC-2),
driving the office deck over Tailscale. When the Swift shell (`mac/`, branch `native-mac`) runs, test each row BY HAND
on a real Mac against the office deck, and tick it here with the date and build.

The Mac column is what the same thing is on a Mac. "Windows fix" says where the Windows answer lives, for reference.
