Layout

The terminal area is a grid of up to 4×4. Place a session with the number keys (hold the cells you want, in reading order — 1 2 3 top row, 4 5 6 next — and release) or by dragging a tile onto it. One shape for the whole deck; changing it clears the current arrangement.

Grid rows × cols

On: moving a session to another window removes it from the one it was in (growing into a neighbouring region never removes). Off: it can be on screen in several windows; the focused window drives its size.

Stepping with F11 / F12 (or Up / Down) is a preview until you click or type; the first Esc undoes the walk and reaches no session.

Asks

Claude sessions can put their questions for you on an ask page (the ask-page skill) instead of in their terminal: one card per question, answered with a click or a note. The asks tile at the top of the sidebar lists every session's, sessions outside the deck included: click it to answer them (F6 or F7 closes); F7 on a session shows just its own. Done types your answers into the session.

What the deck shows
After Done

Sessions in the deck read the first four at their next question (the deck writes them to deck.json in the skill's state folder). Sessions outside the deck keep the skill's own settings.

Sleep

A session nobody is looking at has its process killed and comes back with --resume the moment it is wanted — on screen, typed into, or holding a prompt that is due. The conversation is untouched and resuming costs no tokens; a Claude process is about 244 MB, so this is where the deck’s memory goes. A session that is busy, waiting on you, or holding a prompt never sleeps.

Font

Bundled with the deck (no install needed): Reddit Mono, JetBrains Mono, Fira Code, Source Code Pro, IBM Plex Mono, Inconsolata, Ubuntu Mono. Any font installed on this machine works too. Blank = Cascadia Mono. Licenses: assets/fonts/LICENSES.md.

Large-session resume prompt

Claude Code asks this whenever a big session is resumed, which the deck does on every restart, refresh and account move; the prompt itself costs nothing. Full keeps every detail (the first message afterwards re-reads the history once); summary shrinks the context so later turns cost less. Only "don't ask again" is remembered by Claude Code, per session.

Claude Code never remembers trust for a session rooted at your home folder, so it asks on every launch. With this on, the deck picks "Yes, I trust this folder" for you.

At the deck's next start, each tile still marked paused (the deck's Pause, or a PAUSE pasted into the session) gets the RESUME prompt by itself once its session is up and idle. Off: only "Pause until restart" tiles do; the others keep their mark until their next prompt.

An auditor session (tile menu: Prompts, Make auditor) writes to-<n>.md in its inbox for its child n; the deck types that file into the child as your own message once the child is idle, and moves it to sent. A to-<n>.now.md file is typed at once, interrupting the child's turn (Esc). The inbox's log.md has one line per delivery or refusal.
